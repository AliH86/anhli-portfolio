## Rebuild the live V2 from this branch

`fresh/dist/` was not committed because it is byte-identical to `garden-v2/` on `main` (551 files, `diff -rq` empty).

```bash
cp -R garden-v2/ fresh/dist/
cd fresh && npm ci && npm run build:content -- --verify-library && npm test
```

`--verify-library` reads the audio library in iCloud (`policy.json` → `libraryPathFromHome`); drop the flag if it is not on this machine.
