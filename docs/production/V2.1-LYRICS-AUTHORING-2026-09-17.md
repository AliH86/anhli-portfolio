# Featured lyrics · V2.1

Infrastructure is implemented and tested. No real featured lyrics have been activated: the available catalog contains no supplied timed lyric source. Do not guess, scrape or generate song lyrics.

1. Find the existing track `id` in `fresh/dist/data/catalog.json`. Preserve that ID and the catalog file.
2. Add a separate JSON under `fresh/dist/data/lyrics/`, using an ASCII filename (letters, numbers, `_`, `-`).
3. Add a mapping from the exact track ID to the filename in `fresh/dist/data/lyrics/index.json`.
4. Preview that track. Verify timings against the actual recording, including seeking forward/backward and instrumental gaps. Verify optional host moments with the room closed.

Data contract (field descriptions, not song content):

```json
{
  "trackId": "EXISTING-CATALOG-TRACK-ID",
  "featured": true,
  "lines": [],
  "hostMoments": []
}
```

Each line needs numeric `start` and `end` in seconds and a nonempty `text`; optional `sub` is a second language/translation supplied by the author. Lines must be ordered and must not overlap. Optional `section`: `intro`, `verse`, `pre`, `chorus`, `bridge`, `outro`.

Each host moment needs `time`, `duration` (over zero, at most 12 seconds), `pose` (`sing-soft`, `hum`, `eyes-closed`) and approved `text`. These use restrained existing seated art, not generated lip-sync. A moment is only visible while its track plays, the room is closed and the page is visible. Opening the room, pausing, changing track or leaving its interval restores the ordinary host note.

The loader requests the index on first track selection and only loads registered tracks. Per-track caching avoids repeated requests. Missing or invalid data falls back to the normal music player. The center line is selected from native audio time, with up to two neighboring lines on each side. Instrumental gaps fade the lyric field; a chorus can slightly enlarge the sleeve.

QA fixtures are injected by Playwright in `fresh/scripts/qa-v21.mjs`; they are explicitly labeled QA text and never written into `dist/data/lyrics/`. Tests cover boundaries, gaps, seek, subtitle, malformed timing, lazy loading, unsupported paths, unavailable files, host moment and normal-track fallback.
